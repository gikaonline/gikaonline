GIKA WEBSITE - GITHUB PAGES

1. Open your GitHub repository.
2. Upload ALL items inside this folder (not the ZIP itself):
   - index.html
   - style.css
   - script.js
   - assets folder
   - files folder
3. Commit the changes.
4. In Settings > Pages, keep:
   Source: Deploy from a branch
   Branch: main
   Folder: / (root)
5. Wait 1-3 minutes, then refresh the website.

The website preserves the exact PDF layout as responsive page images.
Clickable areas:
- WORK, ABOUT, CV and CONTACT in the top menu
- Categories on the WORK page
- Download Portfolio PDF
- Download CV
- Email and Instagram on the CONTACT page
